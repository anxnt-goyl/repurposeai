# Product Requirements Document (PRD)

## Target Audience
- Independent creators, podcast hosts, YouTube educators, and startup founders producing regular long-form audio/video content.

## User Personas
- **The Solo Creator:** Records 1 deep conversation weekly; lacks budget for a 5-person agency; needs high-leverage distribution without working weekends.
- **The Founder/Operator:** Speaks on industry panels and podcasts; needs executive LinkedIn thought-leadership without writing from scratch.

## MVP Scope (Strictly Enforced)
1. **Public Surfaces:** Landing page with real product mockups, Sign In, Sign Up.
2. **Dashboard Command Center:** Key metrics, active project status, pipeline progress, recent projects, 3 quick actions.
3. **New Repurpose:** Multi-format file ingestion (MP4, MOV, MP3, WAV, M4A) and YouTube URL ingestion with demo shortcut.
4. **Processing Screen:** Multi-stage animated pipeline with state progress.
5. **Content Workspace:** Overview, Searchable Transcript with moment markers, 12 Scored Moments, Platform Content Tabs, Split Editor with Source Context, and Review Gate.
6. **Chat Workspace:** Contextual episode assistant with Chat History categorized by Today, Yesterday, and Previous 7 days. (No separate Memory product).
7. **Settings:** Profile, Dual Theme (Obsidian & Paper), AI Preferences, Notifications, Integrations (Coming Soon), and Security.
