# Technology Stack Reference

## Frontend
- **Framework:** React 19 (Functional components, custom hooks, Context API)
- **Language:** TypeScript 5.8+ (Strict type safety across domain entities)
- **Build Tool:** Vite 8.3
- **Styling:** Tailwind CSS v4 with bespoke editorial CSS tokens
- **Routing:** React Router v7 (`react-router-dom`)
- **Icons:** Lucide React
- **Animations & Effects:** Motion (`motion/react`), Canvas-Confetti

## Backend (Architecture Target)
- **Runtime:** Node.js 20+
- **Framework:** Express 4.x
- **Database:** MongoDB / PostgreSQL with Drizzle ORM
- **Speech-to-Text:** OpenAI Whisper API / Deepgram Nova
- **Language Models:** Google Gemini 2.5 Flash / Pro via `@google/genai`
- **Deployment:** Render, Vercel, or AWS ECS
